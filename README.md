# July 4th Fireworks 🎆

A self-contained, dependency-free fireworks animation that reads **"Happy July 4th"** across a night sky.

## Features
- **Auto-firing** rockets that launch continuously at random positions and intervals
- **Click anywhere** on the canvas to launch your own firework
- **Red, white & blue** color palettes (with a touch of gold), cycling burst to burst
- **Explosion sound** generated live with the Web Audio API — no audio files needed. Starts muted; click the **Sound** button (top-right) to enable it (browsers require a user interaction before playing audio)

## Run it
Just open [`index.html`](index.html) in any modern browser. No build step, no dependencies.

## Tech
Plain HTML + Canvas 2D + Web Audio, all in a single file.
